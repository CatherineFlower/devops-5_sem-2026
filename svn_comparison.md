# Сравнение Git и SVN

## 1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?

В Git ветка представляет собой легковесный указатель на коммит, поэтому создание и переключение веток выполняется быстро и почти не требует дополнительных ресурсов.

В SVN ветвление исторически связано с копированием структуры каталогов в централизованном репозитории, поэтому работа с ветками менее гибкая и сильнее зависит от сервера.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет. SVN является централизованной системой контроля версий, поэтому для создания коммита необходимо подключение к центральному серверу.

В Git коммиты создаются локально, поэтому интернет для выполнения commit не требуется.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

SVN может использоваться в старых корпоративных и legacy-проектах, где уже существует централизованная инфраструктура и процессы построены вокруг SVN.

Также SVN может быть удобен в проектах, где требуется строгий централизованный контроль структуры репозитория и доступа к отдельным каталогам.
